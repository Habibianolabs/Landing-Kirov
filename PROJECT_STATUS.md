## 1. Что это за проект и какой у него стек

[FACT] Лендинг делается только для Кирова: «G10. Рестораторы и опердиры России. Перезагрузка». Даты в текущем контенте — 5–7 октября 2026 года.

[FACT] Проект статический: браузер получает готовые файлы, без React, Next.js, Vite и без сборки.

- `index.html` — структура страницы, тексты, две формы и служебные окна;
- `styles.css` — визуальная система, адаптивность, состояния фокуса и reduced motion;
- `script.js` — меню, диалоги, карусели, lightbox, cookies, формы и аналитика;
- `api/submit-application.php` — production-обработчик заявок для сервера IHC;
- `api/submit-application.js` — старый совместимый обработчик только для отдельной демонстрационной среды;
- `assets/site/kirov/` — подключённые материалы Кирова;
- `vercel.json` и `package.json` — служебные настройки, runtime-зависимостей нет.

[FACT] GitHub-репозиторий `Habibianolabs/Landing-Kirov` открыт. Ветка `main` на 20 августа 2026 года совпадает с локальной папкой; runtime-файлы и документация сохранены в GitHub.

[FACT] Сервер заказчика — IHC, IP `95.181.224.17`, web-сервер `nginx/1.20.2`, домен `g10.kirov.restoved.ru`. 20 августа проверено: PHP-маршрут отвечает `204` на безопасный `OPTIONS`-запрос и исполняется PHP 7.3.33. Изменения на сервер загружает сисадмин; в этой задаче на сервер не записывались файлы.

[FACT] Ссылка `g10-kirov.vercel.app` используется только как демонстрация frontend для просмотра текущей страницы. Она не является production-сервером заявок и не заменяет загрузку файлов на IHC.

## 4. Что осталось сделать

1. Сисадмин загружает из GitHub новый `script.js` и `api/submit-application.php` на IHC.
2. После обновления выполняется одна согласованная техническая заявка и проверяется получение всеми четырьмя адресатами.
3. Заказчик включает в EnvyBox три модуля: чат поддержки, «Позвонить» и заказ обратного звонка; затем проверяется mobile/desktop-положение виджета.
4. После загрузки hotfix повторно проверяется Яндекс Метрика: просмотр, длительность, CTA и цели формы.
6. Заказчик утверждает открытые материалы: программу, лимит 20/25, цену, 13/14 тем, отзывы и права на фото/Rutube.
7. Завершается финальная проверка адаптивности, доступности, скорости и legal-текстов.

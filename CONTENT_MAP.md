[FACT] В текущей композиции названия блоков остаются видимыми как section-kicker. Крупные заголовки секций от «Экспертов» до CTA-блока удалены; сам CTA-заголовок следующего блока сохранён.

## Статус и правила источников

[FACT] Контент сверялся в следующем порядке: бриф → локальная папка материалов → лендинг Екатеринбурга → утвержденный эскиз → PSD-баннер.

[FACT] Екатеринбург используется только как источник структуры, контента общих блоков и поведения интерфейса. Его визуальный стиль не переносится.

[FACT] Баннер — готовое изображение. Его текст, композиция, цвета, шрифты и элементы не редактируются и не перекрываются элементами сайта.

[FACT] Реализация остаётся статической: HTML, CSS и vanilla JavaScript без React, Next.js, Vite и сборщика. Production-серверная часть для IHC — PHP-обработчик `api/submit-application.php`; legacy-файл `api/submit-application.js` не используется доменом заказчика.

[FACT] Публичный домен `g10.kirov.restoved.ru` обслуживается IHC сервером `95.181.224.17`; этот сервер раздаёт статические файлы и может запускать PHP. Маршрут формы использует `api/submit-application.php`; его загрузка на IHC и проверка ведутся в `MISSING_MATERIALS.md`.

## Глобальная визуальная система

- Фон: статичный светлый голубой градиент с едва заметными диагональными линиями.
- Палитра: холодный тёмно-синий, насыщенный синий, бело-голубой и серебристо-серый из визуальной системы баннера.
- Фоновая графика: малоконтрастный диагональный pattern; она не должна конкурировать с текстом.
- Карточки: слегка полупрозрачные blue-glass surfaces с тонкой синеватой рамкой, мягкой тенью и умеренным радиусом. Это CSS web-аппроксимация frosted glass, а не отдельный нативный Apple-эффект.
- Акценты: синие кнопки, тонкие металлические градиенты только как поддерживающий прием, без имитации 3D-текста баннера.
- Типографика: современный кириллический гротеск для интерфейса; шрифты внутри баннера остаются частью изображения.
- Изображения: реальные материалы проекта. Не использовать изображения Екатеринбурга как дизайн-фон для партнеров Кирова.

## 19. Состояния и служебные сценарии

- Страница без JavaScript: основной контент читаем; формы показывают понятное сообщение или работают через серверный fallback.
- Изображение не загрузилось: сохраняется размер блока и информативный `alt`.
- Программа не утверждена: показывается только согласованный placeholder.
- Фото эксперта в списке альянса отсутствует: сохраняются информативные имя и должность без подстановки чужого лица.
- Ошибка формы: данные пользователя не стираются.
- Повторное открытие модального окна: поля и ошибки сбрасываются, если пользователь не начал ввод.
- Уменьшение движения: декоративные анимации отключаются через `prefers-reduced-motion`.
